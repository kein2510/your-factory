# Your Factory - メカニック・車両整備・パーツクラフト業務管理システム

GTAロールプレイ（FiveM）サーバーなどのメカニックショップ「Your Factory」向けリアルタイム店舗管理・売上・在庫・クラフト・給与査定システムです。

## 主な機能
- **🛒 POSレジ販売**: 車両修理・カスタム・リペアキット等の売上登録、値引き、インセンティブ手当（3割）自動計算
- **🔧 パーツクラフト**: スクラップ素材（鉄くず、スクラップメタル、電子基板など）を消費してリペアキットやチューニングパーツを作成
- **📦 在庫管理**: 車両整備アイテムおよびクラフト素材のリアルタイム在庫・適正在庫数管理
- **👑 幹部管理コンソール**:
  - 従業員管理（ログインPASS、ゲーム内FiveM IDの秘匿管理）
  - 役職設定（工場長、チーフメカニック、主任整備士、一般整備士、見習い）
  - 週次実績・給与ボーナス査定（売上・クラフト・素材調達実績連動、未払い繰越管理）
  - カテゴリー管理（車両整備・カスタムパーツ・リペアキット・素材スクラップ）
  - 工場金庫（Vault）残高管理（店舗手元残り7割の蓄積）
  - 操作ログ（監査ログ）
